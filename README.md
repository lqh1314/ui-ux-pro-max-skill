# UI/UX Pro Max Skill

AI-powered design intelligence for web, mobile, and desktop interfaces.

## Features
- 79 UI styles (50 active)
- 192 product palettes and reasoning profiles
- 74 font pairings
- 119 UX guidelines
- 105 icons
- 17 GSAP presets
- 25 chart types
- 22 tech stacks supported

## Installation
Copy this folder to your skills directory, or use:
```bash
npx skills add https://github.com/lqh1314/ui-ux-pro-max-skill
```

## Usage
The skill activates automatically when you request UI/UX work:
```
Build a landing page for my SaaS product
```
